# painel-pwa

Casca de um app pessoal de finanças, instalável na tela inicial do celular (PWA).

**Este repositório não contém dado nenhum.** Só o programa: a tela de abertura, o
decifrador que roda no navegador, o service worker e o layout. Os números vivem em outro
repositório, privado, num arquivo cifrado com AES-256 que só abre no aparelho, com uma
chave que nunca sai dele.

Os arquivos aqui são gerados por `build_pwa.py`, no repositório do projeto. Editar à mão
não adianta: o próximo build sobrescreve.
